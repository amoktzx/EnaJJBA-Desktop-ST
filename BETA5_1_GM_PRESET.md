# Beta 5.1 · GM Extractor

Расширение уже содержит собственный системный промпт для фонового сканирования. При отправке запроса через ConnectionManagerRequestService текстовые блоки из Chat Completion Prompt Manager НЕ вставляются в сырой GM-запрос; из выбранного пресета используются параметры генерации. Поэтому строгая инструкция дополнительно включена напрямую в beta.js.

Для использования:
1. Импортируйте Ena_GM_GLM_5_3_Flash_Extractor.json через AI Response Configuration → Chat Completion Presets.
2. В Chat Completion выберите GLM 5.3 Flash через Route.me, выберите новый пресет, сохраните.
3. В Connection Manager обновите или создайте отдельный профиль GM, указав эту модель/пресет (Update).
4. В GM → Синхронизация выберите именно этот профиль и продолжите проверку.
5. Не подключайте пресет GM к своему рассказчику: он специально предназначен для выдачи JSON, не прозы.

Примечание: maxTokens в отдельном запросе GM равен 6144 независимо от значения openai_max_tokens в пресете; для обычного чата значение берётся из пресета. Система не делает JSON-schema/response_format принудительно, поэтому сохранена проверка JSON и адаптивное уменьшение блока при сбоях. Полностью завершённые блоки не пересылаются при Continue.
