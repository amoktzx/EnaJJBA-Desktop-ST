# История Ena Desktop

## 1.0.0-beta.3 — независимый GM API и редактируемые события

- Профили SillyTavern Connection Manager для фонового GM-трекера, без смены API рассказчика и без ввода новых API-ключей.
- Редактирование и разделение предложений ИИ до подтверждения.
- Разные типы: объективное событие, знание NPC, подозрение NPC.
- Предпросмотр изменения, проверка источников, видимая кнопка импорта.
- Более атомарный промпт и сохранение прежней системы откатов.

# Changelog

## 1.0.0-beta.1
- Сохранён интерфейс Windows 2000 и двойной клик.
- Полные редактируемые приложения: Видеосалон, Почта, SMS, Справочник, Заметки и GM.
- Миграция данных 0.1/0.2.
- История изменений, экспорт/импорт JSON.
- Источники событий привязаны к отпечатку сообщения и выбранному свайпу.
- Ручная и опциональная автоматическая проверка последних N сообщений через активное подключение SillyTavern.
- Подтверждение извлечённых моделью предложений до применения.
- Откат видимости подтверждённых фактов, когда доказательство удалено/отредактировано/поменяло свайп.
