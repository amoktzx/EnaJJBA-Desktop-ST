# Ena Desktop 2001 · v0.1

Первая **работающая оболочка ноутбука Ены** для SillyTavern: Windows 2000–подобные окна, ретро-иконки, рабочий стол, «Пуск», выключение, игровой календарь под часами, обои и ручные записи.

**Не является готовой автоматической памятью сюжета.** Эта версия намеренно НЕ изменяет чат, НЕ вызывает ИИ, НЕ анализирует Memory Books, НЕ создаёт вымышленные письма/покупки/ранения и НЕ списывает кредиты с OpenRouter.

## Возможности

- Запуск через плавающую кнопку ноутбука и фразу пользователя **«Ена открыла ноутбук»** в новом сообщении (только точное действие Ены, без фонового анализа).
- Скрытие по фразе «Ена закрыла ноутбук» и через «Пуск» → «Выключить ноутбук» (закрывает окна) / «Ждущий режим» (сохраняет окна).
- 8 крупно нарисованных ретро-иконок, классические окна, перетаскивание мышью, разворачивание, сворачивание, таскбар, календарь **под часами**.
- «Архив» разделён на **фильмографию, дискографию, библиографию, аномалии**. Вручную добавляй записи и отмечай статусы, личное владение и «надо пересмотреть». Каталог видеосалона **не** попадает сюда автоматически.
- «Видеосалон»: отдельный учёт лицензий, документов, расходов/доходов и задач; без поштучного учёта клиентов.
- Справочник людей/мест, личный блокнот, GM-панель (ручные записи о следах/травмах, инвентаре, заданиях).
- Почта и SMS — окна-заготовки. Их автосинхронизация появится позднее.
- Настраиваемые **локальные** обои и размер иконок 44–72 px. Дата и время **игровые**, устанавливаются вручную в «Мой компьютер». В отличие от настоящего времени компьютера, они не «бегут» сами.
- Ручные данные записываются в `chatMetadata` **текущего чата** (API SillyTavern). При переключении чата отображаются его собственные данные.

## Как установить на арендованный SillyTavern

**Важно:** штатный установщик SillyTavern принимает **ссылку на Git-репозиторий**, а не произвольный ZIP или файл на компьютере.

1. Распакуй ZIP на компьютер.
2. На GitHub создай **новый репозиторий** (можно приватный, только если хостинг умеет устанавливать такие; надёжнее публичный с кодом без личных данных). Загрузи туда **содержимое** папки `ena-desktop-extension`: `manifest.json`, `index.js`, `style.css`, `assets/` и `README.md` — **в корень репозитория**. Не нужно загружать личные данные/ключи.
3. В SillyTavern: **Extensions → Install Extension**. Вставь URL своего нового GitHub-репозитория и установи **для своего пользователя**, если есть выбор.
4. Перезагрузи страницу SillyTavern. Справа появится маленькая кнопка с компьютером — она открывает ноутбук.
5. На компьютере ярлыки открываются **двойным кликом**, на телефоне — **одним касанием**.

Если твой хостинг предоставляет отдельную загрузку расширений ZIP/папкой, можно использовать её, но это зависит от настроек сервера.

## Проверка без установки

Открой `PREVIEW.html` обычным двойным кликом — это автономная **демонстрация** интерфейса в браузере, со своими временными локальными данными. Она **не** подключена к SillyTavern. Для реальной работы нужны `manifest.json`, `index.js`, `style.css`, `assets/`.

## Факты и откаты — ограничения v0.1

Записи добавляются **вручную**, без связи с конкретными сообщениями. Они не изменяются автоматически при удалении/редактировании сообщения. **Не использовать эту версию как окончательный источник канона для автоматического GM-трекера.** Журнал событий, привязки к сообщениям и свайпам, пересчёт после отката и интеграция с Memory Books — отдельный этап разработки, до запуска автоматической синхронизации.

Обои, загруженные с компьютера/телефона, хранятся только в *локальном хранилище текущего браузера*. Сами текстовые записи — в метаданных чата SillyTavern. Важно регулярно делать экспорт и бэкапы чата.

## Безопасность

Не вводи API-ключи в расширение. Оно не обращается к сторонним сервисам и не отправляет данные в OpenRouter. Названия записей выводятся с HTML-экранированием. Код и изображения оригинальные, не взяты из Phone-ST.

## Структура

- `manifest.json` — метаданные расширения SillyTavern.
- `index.js` — логика рабочего стола, окон, приложений, событий и хранилища.
- `style.css` — визуальные стили Windows 2000 и адаптация под телефон.
- `assets/icons/*.svg` — ретро-иконки (собственная векторная графика).
- `assets/wallpaper.svg` — стандартные обои с городом, заменяемые в настройках.
- `PREVIEW.html` — автономная демонстрация.
