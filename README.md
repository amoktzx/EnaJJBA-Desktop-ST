# Ena Desktop 2001 — v1.0.0-beta.4

Расширение SillyTavern для ролевой игры «Неаполь, 2001»: винтажный компьютер Ены, личный медиаархив, управление видеосалоном, почта/SMS, справочники и отдельная GM-панель. Интерфейс Windows 2000 с **двойным кликом** по иконкам. Без изменения серверного `config.yaml`.

## Beta 4 — единый журнал фактов

В GM → Синхронизация теперь четыре вкладки: **На рассмотрении**, **Принятые**, **Отклонённые**, **Удалённые**. Все четыре статуса хранятся в метаданных текущего чата. ИИ не подтверждает события автоматически.

Защита от повторов сравнивает источники сообщений, тип и категорию факта и краткую дословную цитату. Независимо от формулировки названия:

- `pending` — повтор блокируется, пока факт ожидает рассмотрения.
- `approved` — повтор блокируется; активная запись связана с принятым предложением.
- `rejected` — повтор блокируется; статус можно изменить вручную.
- `deleted` — повтор разрешён; связанная активная запись больше не отображается.
- `split` — технический статус исходного разделённого предложения, который тоже блокирует его повторное создание.

Кнопка **Удалить** переводит факт в «Удалённые», а **Восстановить** возвращает его **на рассмотрение**, не принимает автоматически. При удалении принятого факта его материализованная запись в GM/Архиве/Видеосалоне скрывается.

Совпадение источника и короткой цитаты — **не безошибочная семантическая дедупликация**: если модель выберет совсем другую цитату одного события, похожее предложение теоретически может возникнуть вновь. Повторный анализ всё ещё расходует API-токены.

## Полный экспорт и импорт

**GM → Синхронизация → ⬇ Полный экспорт JSON** выгружает целую базу: `data.beta.proposals` (все статусы), `data.beta.records`, `data.beta.history`, прогресс проверки, каталоги, архив, видеосалон, заметки и схему окон. Не выгружает API-ключи SillyTavern.

JSON можно передать ChatGPT для правки и импортировать обратно кнопкой **⬆ Импорт JSON**. Импорт проверяет формат и **полностью заменяет данные текущего чата**, предварительно автоматически скачав резервную копию. Поддерживаются и прежние полные экспорты Beta 3 с полем `chatData`.

Для безопасной внешней правки **не меняйте `id`, `sources[].key`, `linkedRecordId`, `proposalId`**. При изменении принятого предложения во внешнем JSON связанная запись также обновится. При изменении статуса на `deleted` связанная запись будет скрыта.

Подробности см. [GPT_JSON_GUIDE.md](GPT_JSON_GUIDE.md).

## Установка обновления

1. Экспортируйте предыдущую резервную копию из GM и сохраните чат SillyTavern.
2. Распакуйте ZIP. В GitHub-репозитории `amoktzx/EnaJJBA-Desktop-ST` нажмите **Add file → Upload files**, перетащите содержимое ZIP и подтвердите замену файлов.
3. **Важно:** в корне вместе с `index.js`, `beta.js`, `betaCore.js`, `manifest.json` обязательно должен быть новый файл **`factLedger.js`**. Папка `assets` остаётся на месте.
4. Выполните **Update** для установленного расширения в SillyTavern и перезагрузите страницу.
5. Проверьте в GM → Синхронизация четыре вкладки фактов, импорт/экспорт и повторную проверку небольшого блока чата.

Не нужно удалять и повторно устанавливать расширение; используйте существующий GitHub-репозиторий и штатное обновление.

## Трекер ИИ

В GM доступен выбор сохранённого профиля Connection Manager (например, GLM через Route.me или OpenRouter) либо активного подключения. API-ключи не копируются в расширение. Сканы последних N сообщений, новых сообщений и всей истории порциями работают через выбранный профиль. Автоанализ по умолчанию выключен.

Пока не подтверждайте сразу все предложения массово: модель может ошибаться в сюжете, путать субъективные подозрения NPC с объективными фактами, а точная цитата может меняться между генерациями. Принятые факты, основанные на удалённых или изменённых сообщениях, скрываются, но не уничтожаются.

## Визуал и приложения

Архив: фильмография, дискография, библиография, аномалии, обложки, личные покупки и статусы просмотра. Лицензии салона не переносятся в личный архив. Видеосалон: лицензии, носители для проката, финансы, бумаги и задачи без поштучного контроля каждого клиента. GM: деньги, предметы, внешние следы и травмы, задания, знания NPC, хронология и риски. Настройки обоев/значков и ролевой триггер «Ена открыла ноутбук» сохранены.

Важные технические ограничения: прямая синхронизация с Phone-ST и Memory Books Side Prompts ещё не реализована. Испытания реального платного API на вашем хостинге обязательны отдельно. История хранима в метаданных SillyTavern; экспортируйте копию перед большими правками.

### Если «Полная проверка приостановлена»

Beta 5 показывает подробную причину и номер проблемного блока непосредственно в GM → Синхронизация. Перед обновлением экспортируйте полный JSON. После обновления нажмите «Продолжить полную проверку» (не «Проверить весь чат»). Завершённые блоки и их результаты сохраняются. Если ошибка API содержит 429, дождитесь освобождения квоты; не нажимайте повторно много раз. Для ошибок формата JSON размер блока может уменьшаться автоматически.

### Beta 5.4 — Когда все сообщения имеют is_system=true
Если SillyTavern импортировала обычные игровые реплики с is_system=true, GM больше не отбрасывает их автоматически, когда у сообщения есть имя участника, is_user и непустой текст. Настоящие служебные сообщения исключаются по явной роли/типу/имени. Кнопка «Чтение чата (0 API-запросов)» показывает оба счётчика.

**Прежние 1050/1124 считаются недостоверными**, если они были «обработаны» с нулём фактов до исправления. Сначала сохрани полный JSON, затем проверь чтение без API, протестируй 10 сообщений и только потом нажимай «Проверить весь чат» (это новый проход с начала). Устаревшую кнопку «Продолжить» расширение скрывает и блокирует для такого чата. Удалённые факты, принятые и другие статусы не очищаются автоматически.
